# 公開前チェックリスト

このチェックリストは、非公開案件・契約・社内イベント等に由来する情報を誤って公開しないための最終確認用です。

## 非公開情報

- [ ] 非公開サービス・案件・社内イベントの名称を書いていない
- [ ] 主催者・顧客・実在組織を推測できる固有名詞がない
- [ ] 実問題文・実回答・実データを載せていない
- [ ] 非公開環境でのみ得られる評価値・順位・運用情報を載せていない
- [ ] 非公開データから得た具体的知見・統計値を載せていない
- [ ] 実ファイル名・実フォルダ構造・文書IDを載せていない

## 実装

- [ ] 非公開成果物のソースコードをコピーしていない
- [ ] 固有のExecutor名・ルール・正解値を載せていない
- [ ] 非公開課題に特有のFailure Caseをそのまま載せていない
- [ ] サンプルコード・例は公開情報または独自の架空例から作っている

## 図

- [ ] 実画面・実資料のスクリーンショットを使っていない
- [ ] 実フォルダ名・実文書名が図にない
- [ ] 非公開の実評価値・実評価結果が図にない
- [ ] 架空例・一般概念だけで構成されている

## 契約・規約

- [ ] 現在適用される規約を確認した
- [ ] NDA・社内規程・雇用契約も確認した
- [ ] 判断が曖昧な場合、所属組織またはサービス提供者へ確認した
