# 安全版への書き換え方針

以前の非公開プロジェクトに由来する可能性がある説明を、そのまま匿名化して転用するのではなく、以下の基準でゼロから再構成します。

1. **課題設定を一般化する**  
   「特定の課題を何問解いた」ではなく、「業務文書検索で起こりやすい一般的な問題」として記述する。

2. **具体的成果値を削除する**  
   非公開の評価値、正答率、評価件数、順位、運用回数は使用しない。

3. **Failure Caseを一般化する**  
   非公開資料の固有現象ではなく、PDF変換・OCR・表構造・版管理など公開知識で説明できる一般課題だけ扱う。

4. **実装例を新規作成する**  
   非公開成果物のコードや固有ルールをコピーせず、公開記事用の簡略例を別途作る。

5. **根拠は公開資料へ置き換える**  
   Microsoft Learn、AWS等の公開公式ドキュメントを参照する。
