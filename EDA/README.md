# EDA

このディレクトリには、最終RAGパイプラインを作るまでの探索・検証を保存しています。

- `eda_summary.md`: 実験全体の総括と、最終パイプラインに採用した方針
- `EDA001` から `EDA065`: 各段階の調査、前処理、評価の記録
- `preprocessing_policy.md`: 文書種別ごとの前処理方針
- `human_review.csv`: 人手確認用の記録

最終実行に必要なのはルートの `pyproject.toml`、`scripts/`、`src/`、`materials/`、`questions/` です。EDA は設計意図や再調査のために参照します。
