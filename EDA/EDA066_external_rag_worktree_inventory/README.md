# EDA066: 外部RAG作業ツリーの棚卸し

## 目的

`SIGNATE` 直下に作成された `SIGNATE_Agentic_RAG_*` の作業ツリーを、最終RAGパイプラインと混同しない形で整理する。各ツリーには大容量の `data/output/` が含まれるため、Gitへは再現に必要なメタデータ、差分パッチ、未追跡のPythonソースだけを保存する。

## 保存方針

- `worktree_inventory.md` にツリー名、ブランチ、基点コミット、扱いを記録する。
- `patches/` には未コミットの追跡済みソース差分を保存する。
- `source_snapshots/` には未追跡の実装・テストだけを保存する。
- 原本、仮想環境、`data/work/`、`data/output/` は巨大かつ再生成可能なため保存しない。

## 結論

Excel行到達性監査とPowerPointタイムライン統合の実装は、実験系の分岐として記録した。今回の完成パイプラインへは直接取り込まず、必要時にここに保存した差分を評価して採用する。その他の作業ツリーは、主に出力だけを持つ検証実行であり、結果の所在を記録する。
